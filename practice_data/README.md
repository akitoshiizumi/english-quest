# 同梱教材

このフォルダのMP3と既存JSONをリポジトリに含めています。
教材本文・字幕・単語時刻・語彙は `dataset/starter/` のSQLiteスナップショットから
初回起動時に `dataset/vocab.db` へ復元されます。

保存済み教材の再生と語彙練習にはAPIキーもFFmpegも不要です。
このフォルダだけでは、SQLiteに保存されたすべての教材情報は復元できません。

新しく生成した `english_overlap_*.mp3` と旧形式の `english_overlap_*.json` も
Gitの追加対象になります。教材情報を配布し直すときは、更新したデータベースの
スナップショットも同時に作成してください。
