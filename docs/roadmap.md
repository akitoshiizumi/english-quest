# 開発順序

| 段階 | チケット | 到達点 |
|---|---|---|
| 0 | 仕様とチケットの初版（整備済み） | 要求、操作、API更新方針、受け入れ条件がある |
| 1 | T-001 → T-002、T-003 | 既存資産の理解、移行・復元、構成整理 |
| 2 | T-014、T-004、T-005 → T-006、T-007 | テスト基盤、API接続基盤、2キーとマウスによる語彙学習、記録、管理 |
| 3 | T-008、T-009、T-010 | 復習と統計、難易度、候補選択と類似除外 |
| 4 | T-011 → T-012 | 対象語から教材作成、音声練習、記録の統合 |
| 5 | T-013 | カテゴリ内の未習得語上位50件などから一連の練習を開始 |
| 6 | T-015 → T-016 | React GUIと機能別タブへ移行 |
| 7 | T-017、T-018、T-019 | 語彙練習内での教材作成、自動CEFR評価、活動時間の分離統計 |

依存関係の正本はチケット一覧。段階は公開時期や日付を約束するものではない。実装が進んだ時点で見積もる。各段階で実際に利用できる単位に仕上げる。

仕様に追加があれば要求IDとチケットを作り、依存・受け入れ条件・優先度を設定する。
