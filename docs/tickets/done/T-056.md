# T-056: Keep sentence repeat active during sentence navigation

- Status: Complete
- Priority: P1
- Requirements: OVER-004, OVER-005
- Dependencies: T-037, T-053

## Background

Pressing the configured current sentence key (A by default) calls the general sentence-navigation helper, which clears the active sentence repeat. Learners expect only the configured repeat key or repeat button to toggle sentence repeat.

## Scope

- Included: Preserve sentence-repeat selection and playback when the current sentence navigation key is used; ensure only the configured repeat key or the repeat button toggles repeat on/off.
- Excluded: Changing key defaults or sentence seek targets.

## Acceptance criteria

- [x] Pressing the configured current sentence key while a sentence is repeating does not turn repeat off.
- [x] Pressing the configured sentence-repeat key toggles repeat on and off; clicking the active repeat button still cancels it.
- [x] Previous sentence navigation retains its existing behavior and does not toggle repeat.

## Implementation

Sentence navigation no longer clears `sentenceLoopIndex`. When playback exits the repeat clip for navigation, the repeat target stays selected and is reconstructed after its inter-repeat pause; the configured repeat key and its button remain the controls that cancel or switch repeat.
