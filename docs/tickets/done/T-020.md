# T-020 テスト用・本番用教材データの分離

- 状態: 完了（2026-10-24）
- 優先度: P1
- 要求ID: DATA-004, TEST-001
- 依存: T-012, T-014

## 目的

本番教材を保ったまま、テストが本番の `practice_data` を参照・更新しない境界を明示し、保存先を利用者が識別できるようにする。

## 受け入れ条件

- [x] 本番の保存先とテストの保存先を明示し、サーバー応答・画面から現在の保存先を確認できる。
- [x] 自動テストは隔離された一時教材フォルダのみを利用する。`practice_data` と既存データにアクセスしない。
- [x] 保存・一覧・読み込みの対象が常に現在の起動時保存先内に限定される。
- [x] 既存本番教材を移動・削除せず、従来の保存先から利用できる。

## テスト

保存先選択とパス境界の統合テスト、E2Eで保存場所表示・一覧の隔離を確認する。既存 `practice_data` は読み書きせず、合成教材と一時ディレクトリを使う。

実施結果（2026-10-24）: `npm.cmd test` 成功（Python 44件、キーボード3件、Playwright 12件）。個別には `py -m unittest tests.test_storage_and_pages tests.test_http_integration -v` 18件、`npm.cmd run build` 成功、`npm.cmd run test:e2e` 12件。合成E2Eは `overlap-e2e-*` 一時ディレクトリを使用。既存 `practice_data` は操作していない。
