# T-024 語彙練習セットの進捗表示

- 状態: 完了
- 優先度: P1
- 要求ID: UX-001, VOC-001, STAT-002
- 依存: T-005, T-019, T-022

## 目的

選択した件数に対して現在の出題位置と完了状況を示し、語彙練習の残り量を把握できるようにする。

## 受け入れ条件

- [x] 練習中に現在問数と設定件数を表示する。
- [x] 次問へ進むたびに進捗が更新され、完了時は完了状態を明確に示す。
- [x] 新しい練習を開始すると進捗がリセットされ、該当語がない場合は誤った進捗を表示しない。
- [x] 表示は読み上げ可能で、キーボード・マウスの既存操作を妨げない。
- [x] Playwrightで1問セット・複数問セット・完了・再開始を確認する。

## テスト

E2Eの一時DBにある合成語彙だけで確認し、統合・全体テストも実行する。

## 実施結果

- 語彙練習カードに現在問数/セット件数を表示し、次問・完了・新しい練習開始・該当語なしの状態を示す。
- 進捗表示は `aria-live="polite"` で読み上げ可能。既存のボタンとA/U/S/I操作を維持。
- 合成DBの1問・2問セットで進行と完了を確認し、再開始時のリセットとC2で該当語なしの表示も確認。
