# T-030: Learning dashboard statistics resilience

- Status: Complete
- Priority: P1
- Requirements: STAT-001, STAT-002, STAT-003
- Dependencies: T-028

## Background

The dashboard displayed an undefined-property error instead of statistics. The frontend assumed every API response contained all-time database statistics and vocabulary performance. A missing field stopped rendering the period summary and daily rows too.

## Scope

- Included: Render dashboard sections independently for absent or malformed API fields; lock the statistics endpoint contract with isolated integration tests; verify the dashboard and partial-response regression with Playwright.
- Excluded: Changing existing statistics calculations.

## Acceptance criteria

- [x] A complete response renders database metric cards, vocabulary performance, period summary, and daily rows.
- [x] Missing or malformed all-time fields do not prevent period statistics from rendering; affected sections show a clear fallback.
- [x] Integration tests assert the statistics response shape and values with a temporary fixture database.
- [x] Playwright covers the complete dashboard and a partial legacy response without production data or paid APIs.
