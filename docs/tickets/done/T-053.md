# T-053: Make sentence playback controls persistent and configurable

- Status: Complete
- Priority: P1
- Requirements: OVER-005
- Dependencies: T-012, T-015

## Background

Sentence practice currently depends on keyboard shortcuts and controls in the document flow. Learners need configurable sentence navigation and access to playback controls while reading long materials.

## Scope

- Included: Add configurable A/W sentence navigation keys; keep playback controls and audio settings visible beside the sentence text while the text area scrolls; retain existing repeat-key and silence settings.
- Excluded: Changing audio generation, sentence timing, or vocabulary shortcuts.

## Acceptance criteria

- [x] A configurable key (default A) seeks to the start of the current sentence and resumes playback from there.
- [x] A configurable key (default W) seeks to the beginning of the previous sentence and resumes playback there; the first sentence stays at the beginning.
- [x] Playback controls and audio settings remain visible beside the scrollable sentence area while scrolling through long text, including a narrow-screen usable layout.
- [x] Keyboard shortcuts do not trigger while focus is in editable fields, during IME composition, or with modifier keys; existing Space and repeat-key behavior remains intact.
- [x] Settings persist and the UI shows the configured key assignments.

## Implementation

The playback area now uses a scrollable sentence column and a sticky control/settings sidebar. Local audio settings store independent silence durations and distinct repeat/current/previous sentence keys. Configurable A/W navigation seeks to a timed sentence start and resumes playback there; W at the first sentence remains at the first sentence. The E2E scenario covers key navigation, editable field protection, settings persistence, and sticky sidebar behavior.
