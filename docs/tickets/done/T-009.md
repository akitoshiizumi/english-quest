## 実装結果

語義ごとCEFR評価を Responses API の strict JSON Schema で推定する。レベル・日本語根拠・モデル・時刻・手動設定フラグを保存。未判定100件まで選択、概算費用表示、ジョブ進捗・一時停止・再開を実装。手動指定のレベルは自動処理で上書きしない。

## 確認結果


npm.cmd test 成功（Python 36件、キーボード3件、Playwright 7件）。Python fixture は temporary SQLite 上の自動B2/手動B1、応答トークン記録、一時停止時にAPI providerを呼ばないケース。E2E は synthetic 3語義の見積り→ジョブ開始→完了表示を確認。手動CEFR補正と未判定の除外は統合試験で確認。実OpenAI呼び出しなし。fixtureは `tests/fixtures/vocabulary.json` と `tests/test_difficulty.py`。

## 判断・残課題

推定は学習補助であり専門的なCEFR認定ではない。代表fixtureはAPI応答形式・手動値保持の動作確認で、語彙教育上の精度検証には実データを用いたレビューが必要。未判定語義は一括評価に含めるまで学習画面で「未判定」と表示する。
