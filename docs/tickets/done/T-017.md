# T-017 語彙練習内での教材作成

- 状態: 完了
- 優先度: P1
- 要求ID: GEN-002, FLOW-001, SELECT-001, COVER-001
- 依存: T-011, T-013, T-016

## 目的

教材作成を独立した機能・タブとして扱わず、語彙練習の条件設定からオーバーラッピング用英文を作成できるようにする。

## 受け入れ条件

- [x] 語彙練習タブの条件・フィルタにカテゴリ、方向、習熟状況、件数、CEFR難易度、未学習語を含めるかをまとめる。
- [x] 同じ条件から語彙カード学習と「選択語で重ね読み用英文を作成」を選べる。
- [x] 教材作成を独立タブや独立した上位ナビゲーション項目として表示しない。
- [x] 生成前に対象語と理由を確認でき、0件・対象不足を案内する。
- [x] 選択語彙から英文を作成・編集・保存し、保存後にオーバーラッピングタブへ移動できる。
- [x] 対象数、使用数、未使用語、使用箇所、生成条件、モデルを維持し、途中失敗から再開できる。
- [x] 既存の前回条件再利用、API費用目安、キーボード操作を維持する。

## テスト

合成データで条件選択から語彙練習・英文生成・保存・オーバーラッピング開始までをPlaywrightで確認する。対象0件、対象不足、途中失敗・再開はHTTP統合テストで確認し、有料APIは使用しない。


## 実装・検証結果 (2026-10-24)

- 語彙練習タブ内にカテゴリ、方向、習熟状況、件数、CEFR、未学習語の共通条件を配置。カード練習と教材候補の両方に適用し、件数到達で練習を終了する。
- 教材作成を語彙練習タブに集約。語彙選定の理由・費用目安を確認し、英文を編集・保存できる。保存後は英文と教材IDをオーバーラッピング画面に渡す。
- 前回条件の復元、使用語彙・使用箇所・未使用語・モデル・費用・途中失敗したジョブの再開を維持。
- HTTP統合テストで習熟状況フィルタ、0件、条件保存、固定providerでの生成・使用量記録を確認。E2Eで共通フィルタと件数上限、候補選択から生成・編集・保存・画面移動・音声再生を確認。
