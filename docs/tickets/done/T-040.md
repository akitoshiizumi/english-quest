# T-040: Lengthen sentence repeat pause and add a short lead-in

- Status: Complete
- Priority: P1
- Requirements: OVER-004
- Dependencies: T-039

## Background

The one-second silence between repeated sentences is too short for speaking along. Starting exactly at the first word also gives no lead-in before the sentence begins.

## Scope

- Included: A 1.5-second silent interval and a short 0.25-second lead-in before the selected sentence for initial selection, automatic repeats, and manual resume.
- Excluded: Changing audio files or word timestamps.

## Acceptance criteria

- [x] Repeats pause audio for 1.5 seconds before restarting.
- [x] A selected sentence starts 0.25 seconds before its first timed word, clamped at audio time zero.
- [x] The lead-in applies when switching targets and resuming after pausing during the repeat gap, without affecting ordinary playback or Space controls.
- [x] Isolated E2E timing and second-sentence seek checks pass with existing regression tests.

## Implementation

The repeat gap is controlled by a 1500 ms constant. Initial selection, automatic repeat, Space resume from a paused gap, and play from a completed sentence all use the same clamped 0.25-second lead-in. The R-key current-sentence lookup includes that lead-in so it keeps the selected sentence during the pre-roll.
