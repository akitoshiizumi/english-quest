## 目的・実装範囲

候補抽出と完全一致・ベクトル類似判定を実現し、関連要求を満たす。

## 受け入れ条件

- [x] 英文と語彙リストの両方から候補を作り、選択したものだけ登録できる。
- [x] 正規化一致、既存語との類似、候補同士の重複を判定する。
- [x] 同一モデル・次元・入力形式のベクトルでコサイン類似度を計算する。
- [x] 合成fixtureで重複・類義・異義の組の閾値を評価し、除外理由・一致先・スコアと再選択を提供する。
- [x] 埋め込みキャッシュと欠損分の再実行を実装し、既存similarの流用可否を明記する。

## 実装結果

英文/語彙リストから候補抽出し、英語見出しが英語・意味が日本語となる形で確認後に選択登録。正規化完全一致とバッチ内重複を事前表示。Embedding APIのキャッシュ・モデル/次元/入力版を分離し、cosine閾値をUIから指定、既存語との類似先とスコアを表示して採否を再選択可能。類似候補にはAPI比較を明示。

## 確認結果


npm.cmd test 成功（Python 36件、キーボード3件、Playwright 7件）。固定ベクトルfixtureで完全一致、同義寄り、異義、閾値、索引なし、キャッシュ再利用を確認。Playwrightで既存語完全一致・バッチ重複・閾値0.91の送信と類似結果表示を確認。実データと有料APIは不使用。

## 判断・残課題

旧 similar テーブルはモデル、次元、入力形式が不明のため再利用しない。類似度判定は自動削除せず、人がチェックボックスで判断する。実際の辞書で最適な閾値が決まったわけではないため、初期値0.80は運用で調整する。
