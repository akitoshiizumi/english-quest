# T-022 UXエキスパートレビューと改善計画

- 状態: 完了
- 優先度: P1
- 要求ID: UX-001, UI-001, UI-003, UI-004, VOC-001, STAT-002
- 依存: T-015, T-019, T-021

## 目的

英語学習者の利用目的と学習フローに照らして、アプリ全体の使いやすさ・分かりやすさ・アクセシビリティを専門的なUX観点から評価し、改善の優先順位を決める。

## レビュー範囲

- オーバーラッピング、語彙練習、語彙管理、語彙追加、データベース管理の5タブ
- 代表シナリオ: 起動して学習を始める、語彙を回答・評価する、苦手語から英文教材を作って練習する、保存教材を選んで再生する、学習時間を振り返る
- マウス・キーボード・狭い画面での操作、表示状態・エラー・空状態、ラベルとフォーカス

## 受け入れ条件

- [x] 一貫性、情報の優先順位、ナビゲーション、フィードバック、エラー防止、アクセシビリティ、レスポンシブ性の観点で評価する。
- [x] 各指摘に画面/シナリオ、再現手順、利用者への影響、深刻度、根拠、改善案を記録する。
- [x] 問題がない項目も確認範囲と方法を明記し、重大度の判断基準を示す。
- [x] 改善候補を影響度・頻度・実装規模で並べ、上位課題を独立チケットに分割する。
- [x] 操作を伴う確認はPlaywrightで再現可能にし、必要な回帰/E2Eテストをチケットへ記録する。実ユーザー調査を行っていない場合は専門家レビューと区別して明記する。
