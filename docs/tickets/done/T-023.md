# T-023 語彙練習の状態別キー案内を明確化

- 状態: 完了
- 優先度: P1
- 要求ID: UX-001, UI-001, UI-002
- 依存: T-006, T-021, T-022

## 目的

語彙練習でキー操作の意味が問題表示中と答え表示後に変わることを、画面だけで正確に理解できるようにする。

## 受け入れ条件

- [x] 問題表示中はA/U/S/Iのどれでも答えを表示することが分かる。
- [x] 答え表示後はA/Uが「もう一度」、S/Iが「覚えていた」を記録すると分かる。
- [x] 設定変更後の実際のキー割り当てと案内表示が一致する。
- [x] Playwrightで案内、状態遷移、キー・ボタンの操作を確認する。

## テスト

合成語彙を使い、英→日・日→英の回答経路と保存済みキー設定をE2Eで確認する。

## 実施結果

- 語彙練習の案内を状態別に説明し、設定されたキー割り当てから実際の案内文を生成。
- 問題表示中は回答キーすべてで答えを表示し、回答後は「もう一度」「覚えていた」のキーを案内する。
- E2Eでは初期設定とカスタムQ/W設定、Uで答えを表示、Qで評価保存、初期値への復帰を確認。
