# T-070: Track cumulative learning goals on the dashboard

- Status: 完了
- Priority: P2
- Requirements: STAT-006
- Dependencies: none

## Background

Learners need a clear cumulative target for overlap listening time and vocabulary exposure, along with current progress toward each target.

## Scope

- Included: Let the learner set or clear lifetime overlap-hours and distinct-vocabulary targets on the dashboard; show lifetime progress, remaining amount, and a progress bar; keep these figures independent of the dashboard's selected date range. Persist targets in existing app settings.
- Excluded: Deadlines, streaks, notifications, and counting old legacy vocabulary history that lacks per-answer events or duration.

## Acceptance criteria

- [x] Dashboard allows saving and clearing overlap-hours and distinct-vocabulary targets independently.
- [x] Dashboard shows current cumulative overlap activity time and distinct vocabularies answered at least once, with target, remaining amount, and an accessible progress bar.
- [x] Progress updates after new overlap activity or vocabulary answers and remains cumulative regardless of the selected statistics period.
- [x] Targets persist across page reloads; invalid, negative, or out-of-range inputs produce a clear error and are not saved.
- [x] Missing targets have a clear unset state, and progress never exceeds 100% while actual totals remain visible.

## Implementation

- Added `/api/learning-goals` GET/POST backed by the existing `app_settings` table; no schema migration is needed.
- Added independent optional targets for overlap hours and distinct answered vocabulary, with validated ranges and per-target clearing.
- Dashboard now shows lifetime actuals, target, remaining amount, and accessible progress bars capped at 100%; actual totals remain visible above goal. Current overlap time is displayed to 0.01 hour.
- Goal progress reloads after vocabulary answers, recorded overlap activity, date-range changes, and page reload.
- Documented lifetime counting and legacy-history limitations. Added isolated database, HTTP integration, and dashboard E2E coverage.

## Limitations

Lifetime duration is based on recorded overlap activity since event logging was introduced; legacy records without duration are excluded. Vocabulary progress counts distinct vocabularies with at least one new-format answer, whether rated known or again.
