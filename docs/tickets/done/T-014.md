## 目的・実装範囲

- [x] 一時DB・一時教材ディレクトリの作成とリセットを自動化する。既定のテストコマンドが実データを読まないことを確認する。

- [x] E2Eツールを選び、クリーンな起動・終了、待機、証跡保存を含むコマンドを文書化する。
- [x] A/U・S/Iの語彙学習、カテゴリからの教材作成・オーバーラッピングのE2Eひな形を実行する。

## 実装結果

合成fixture `tests/fixtures/vocabulary.json` と README、Python unittest、固定応答を注入するAPI境界、Playwright + Chromium のE2E起動・終了、画面証跡、Windows GitHub Actionsを追加。`package.json` の `npm test` が全テスト層を実行する。

## 確認結果

`npm test` — Python統合・単体36件、キー操作3件、Playwright 7件が成功。英日・日英キー学習、設定永続化、失敗時の回答保持、教材選定→固定生成→編集保存→固定音声再生・字幕追従・時間記録を確認した。E2Eアーティファクト: `tests/e2e-artifacts/`（無視対象）。Python fixtureは各テスト内の一時DB。OpenAI境界の単体・統合確認はprovider固定応答。ネットワーク/APIキー不要。
