# T-052: Keep study material generation resilient to non-Japanese notes

- Status: Complete
- Priority: P1
- Requirements: GEN-002, FLOW-001
- Dependencies: T-035, T-051

## Background

Overlap material generation can reject the entire article when generated Japanese translations or vocabulary meanings contain foreign-language text. A prompt retry is useful, but one malformed note should not discard the rest of a usable article.

## Scope

- Included: Clarify Japanese-only instructions and retry feedback; remove non-Japanese text from translations that remain malformed; omit vocabulary notes whose Japanese meanings remain malformed; preserve valid sentences and notes; avoid aborting the complete material for these content errors.
- Excluded: Changing article text, speech synthesis, or vocabulary matching behavior.

## Acceptance criteria

- [x] Prompts clearly distinguish the source English text and English vocabulary headwords from Japanese-only translations and meanings.
- [x] A malformed translation triggers a targeted retry; if still malformed, foreign-language text is removed and the rest of the sentence/article remains available.
- [x] A vocabulary entry with a malformed meaning is retried, then omitted if no Japanese meaning remains; valid entries remain.
- [x] A whole-material generation error is not raised solely because a note contains foreign-language text; malformed response shape still produces a clear failure.
- [x] Unit, isolated integration, and Playwright regression coverage follows the ticket test policy.

## Test plan

- Unit: Deterministic Responses fixtures for mixed Japanese/Arabic/Latin text, all-foreign translation, invalid vocabulary meaning, and valid notes; verify retry instructions and sanitized output.
- Integration: Exercise the overlap generation endpoint with the deterministic provider seam and temporary storage/database; ensure unaffected blocks remain available.
- E2E: Mock generated material containing a contaminated note and verify audio/material display retains valid content without the legacy error.
- Other validation: `npm.cmd test`.

## Test data / fixtures

- Synthetic English sentences and Japanese notes with injected Arabic and Latin spans; no production data and no paid API calls.

## Implementation

- Rewrote the prompt to require Japanese-only translations and meanings, keeping English only in source-matched vocabulary headwords. The second request identifies which sentence fields need correction.
- Added a local cleanup pass for remaining foreign-script text. Japanese translation text survives; a translation with no Japanese content gets a Japanese omission note. Vocabulary meanings are cleaned and entries are omitted only when no Japanese meaning remains.
- The overlap endpoint and saved subtitle data continue with the article rather than failing because of contaminated notes. Invalid response shape still fails clearly.

## Limitations

If every character in a translation is foreign text, the sentence remains in the article and displays `（日本語訳を省略）`; vocabulary notes with no Japanese meaning are omitted.
