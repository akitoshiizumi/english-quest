# T-043: Simplify database counts and collapse vocabulary performance

- Status: Complete
- Priority: P2
- Requirements: STAT-003
- Dependencies: T-028

## Background

The dashboard shows the total vocabulary count, active learning-target count, archived count, and sense count as separate cards even when those values are identical. The all-time vocabulary performance table also lengthens the dashboard for users who only need other statistics.

## Scope

- Included: Collapse the all-time vocabulary performance area with an accessible disclosure control; show one vocabulary count when registered, active, and sense counts coincide, and show clear distinctions only when counts differ.
- Excluded: Changes to database counting semantics or API storage.

## Acceptance criteria

- [x] The all-time vocabulary performance can be opened and closed by mouse and keyboard, and starts closed.
- [x] Duplicate inventory counts appear once when they are equal; when active or sense counts differ, the dashboard labels the distinct concepts clearly.
- [x] Learning totals and vocabulary performance search/sort remain available and correct.

## Implementation

Wrapped the all-time per-vocabulary table in a native `<details>` disclosure, closed by default. The inventory cards show one `語彙` count when registered, active, and sense counts are equal; otherwise they show registered vocabulary, active learning targets, and senses. Added explanatory copy for the three definitions. API values and learning aggregate calculations are unchanged.
