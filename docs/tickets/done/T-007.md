## 目的・実装範囲

語彙と教材の管理画面を実現し、関連要求を満たす。

## 受け入れ条件

- [x] 検索・絞り込み・編集・アーカイブ・エクスポートができる。
- [x] 語義、品詞、タグ、出典を扱い、既存教材の参照を表示する。
- [x] 履歴参照を保持し、物理削除・復元の扱いを文書化する。

## 必須のテスト確認

- 統合テスト: 実行コマンド、結果、影響を受ける経路を記録する。機能変更では必須。
- E2Eテスト: 受け入れ条件に対応する画面操作シナリオ、実行コマンド、結果を記録する。画面を通る変更では必須。
- 該当しないテスト層があれば、その理由を記録する。
- テストデータ: 使用・追加したfixtureと期待値を記録する。実データ・実APIを使わない。
- テスト未実施や失敗がある間は完了にしない。[テスト方針](../../testing.md)を参照。

## 実装結果

語彙の検索・表示・編集・アーカイブ/復元とCSV出力、教材の検索・編集・アーカイブ/復元・CSV出力を追加。教材は本文、語彙数、状態を一覧表示。出典・品詞・語義を保持する。旧練習ファイルは従来の保存済み一覧から再生できる。

## 確認結果


npm.cmd test 成功（Python 36件、キーボード3件、Playwright 7件）。合成語彙・教材fixtureで画面検索、アーカイブ/復元、教材CSVダウンロード、既存の語彙一覧回帰を確認。Python fixture/一時DBで語彙CSV APIも確認。実dataset/practice_dataはテストから参照していない。

## 判断・残課題

削除操作はアーカイブのみ提供し、学習イベント・教材リンクを残す。物理削除は通常の管理画面では提供しない。復元はアーカイブ状態の解除。DBの物理削除が将来必要な場合は、バックアップのうえ孤児参照を確認する専用保守手順を要する。旧practice_dataのファイル自体は従来一覧で参照するが、DB教材CSVはデータベース登録済みの教材を対象とする。
