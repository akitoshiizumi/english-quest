## 必須のテスト確認

- 統合テスト: 実行コマンド、結果、影響を受ける経路を記録する。機能変更では必須。

- 該当しないテスト層があれば、その理由を記録する。
- テストデータ: 使用・追加したfixtureと期待値を記録する。実データ・実APIを使わない。
- テスト未実施や失敗がある間は完了にしない。[テスト方針](../../testing.md)を参照。

## 実装結果

OpenAI呼び出しをサーバー側の injectable boundary に集約。用途別モデル・単価設定、safe error、usage/rate_version、バックグラウンドjob状態とpause/resume/retryを実装。テキスト生成・候補抽出・難易度判定・埋め込み・Realtime音声・Whisper文字起こしを記録。候補抽出と類似度比較のjob/usage漏れを本チケット完了時に修正。APIキーを画面応答に含めない。

## 確認結果

`npm.cmd test` — Python 36件、キー操作3件、Playwright 7件すべて成功。API境界、例外分類、固定providerによる候補抽出/類似比較のjob・usage保存、教材生成・難易度評価・音声生成のusageをtemporary SQLiteで確認。Playwrightは利用者フロー、キー非表示を含む全体回帰を実施。実API・実DB不使用。音声単語時刻はWhisper word timestampの現行制約を資料とコードで確認。

## 判断・残課題

選定根拠・料金・確認日は[OpenAI API方針](../../openai-api-policy.md)に記録。Whisperの単語時刻対応は現時点の互換性例外で、公式の停止予定より前に代替案を再評価する。自動テストはAPI課金を発生させない。
