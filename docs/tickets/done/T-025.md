# T-025 語彙フィルター教材作成をオーバーラッピング画面へ移動

- 状態: 完了
- 優先度: P1
- 要求ID: GEN-002, FLOW-001, UI-003
- 依存: T-017, T-022

## 目的

フィルターした語彙から重ね読み用英文を作成する機能を、オーバーラッピング画面で見つけて完結できるようにする。

## 受け入れ条件

- [x] 「フィルタした語彙で重ね読み用英文を作成」と語彙フィルターをオーバーラッピング画面に配置する。
- [x] 語彙練習画面の出題フィルターと教材作成用フィルターは独立して動作し、選択や重複IDの競合を起こさない。
- [x] 対象語の確認・選択、概算表示、英文生成、失敗からの再開、編集・保存がオーバーラッピング画面から操作できる。
- [x] 保存後に生成英文がオーバーラッピングの音声生成欄へ引き継がれ、そのまま音声・字幕を生成できる。
- [x] 教材作成用フィルターは前回条件を復元し、画面を再読込しても選択条件を保つ。
- [x] Playwrightで教材生成から保存、重ね読み画面での音声生成までを合成データで確認する。

## テスト

`npm.cmd test` を実行する。Playwrightの一時DB・合成語彙・固定生成応答・合成WAVを使い、本番データと実APIを使わない。

## 実施結果

- 教材作成カードと教材用カテゴリ・方向・件数・習熟状況・未学習語・CEFRフィルターをオーバーラッピングタブへ移動。
- 語彙練習用フィルターは独立したまま維持。教材条件は保存・再読込後に復元し、生成状態はオーバーラッピング画面で通知。
- 保存した教材を音声生成欄へ引き継ぎ、同画面で音声・字幕生成と再生へ進める。

## テスト結果

- `npm.cmd test` — 成功（TypeScript/Vite build、Python 44件、キーボード3件、Playwright E2E 16件）。
- E2Eは一時DB、合成語彙、固定生成応答、合成WAVを使用。教材生成・保存・音声生成・再生、条件復元、フィルター独立性を確認。
- `py -m compileall -q english_overlap tests`、`git diff --check` — 成功。
