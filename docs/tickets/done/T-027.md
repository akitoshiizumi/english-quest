# T-027: 語彙練習に最大1000件と直近成績フィルターを追加

- Status: Complete
- Priority: P1
- Requirements: VOC-002
- Dependencies: none

## Background

現在の語彙練習は対象件数上限が小さく、直近の学習結果で対象語を選べない。大量の語彙をまとめて学習し、直近の苦手語や全回不正解の語を絞り込みたい。

## Scope

- Included: 語彙練習の対象数を最大1000にする。過去N回の自己評価正解率と、記録された全回で不正解の語を絞り込む。
- Excluded: オーバーラッピング用語彙生成フィルターの件数変更。

## Acceptance criteria

- [x] 語彙練習の件数を1〜1000で指定でき、初期値と既存条件の復元が正しく動く。
- [x] UIとAPIの双方が1000を上限として検証し、上限超過を安全に拒否または制限する。
- [x] 選択方向の直近N回（Nを利用者が指定）の自己評価正解率で語彙を絞り込める。対象件数がN未満の語の扱いを明示して選べる。
- [x] 「全回間違い」フィルターが選択可能で、少なくとも1回の対象方向の学習記録があり、全記録が不正解の語だけを返す。未学習語と履歴なしの語は混同しない。
- [x] フィルターを組み合わせても、出題件数・キーボード操作・学習記録の既存動作が保たれる。

## Test plan

- Unit: 0件、N未満、N件、混合正誤、全回不正解、方向別履歴、1000/1001件境界。
- Integration: 一時DBで履歴集計・フィルター・上限検証を確認。
- E2E: 条件指定から出題開始までをマウスとキーボードで確認し、正解率条件・全回不正解・上限超過を検査。
- Other validation: `npm test`。

## Test data / fixtures

- 一時DBに、未学習、全正解、混合、全不正解、方向別記録、履歴数がN未満の語を含む合成履歴を追加。
- 1000件以上の合成語彙を使い境界を確認。本番DB・practice_dataは使わない。

## Implementation

`database.fetch_vocabulary_question` に方向別直近評価と全回不正解の条件を追加し、HTTP API側で件数上限を検証。語彙練習UIに最大1000、直近N回・自己評価率上限・履歴不足の扱い・全回不正解を追加。
