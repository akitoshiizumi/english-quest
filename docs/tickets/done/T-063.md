# T-063: Show AI summaries in saved material details

- Status: 作業中
- Priority: P1
- Requirements: DATA-009, DATA-007
- Dependencies: T-061, T-062

## Background

The saved-material metadata panel in the overlap screen shows the stored material summary, but it does not show the AI summary generated from material management. Learners should be able to review that AI summary when opening the saved material.

## Scope

- Included: Display a clearly labeled AI summary in the saved-material metadata panel for file-backed and text-only materials; show a clear not-yet-generated state when no AI summary exists; display only summaries with AI-generation provenance so legacy short descriptions are not mistaken for AI summaries.
- Excluded: Generating or regenerating summaries from the overlap screen, editing summaries, or changing summary generation and billing behavior.

## Acceptance criteria

- [x] Selecting a file-backed or text-only saved material displays its AI summary in the metadata panel when AI summary metadata exists.
- [x] Materials without an AI-generated summary show an explicit not-yet-generated message; legacy JSON descriptions are not presented as AI summaries.
- [x] Showing saved material details makes no API call and does not change existing summary metadata or file-backed playback.

## Test plan

- Unit: N/A; the change has no independent calculation or persistence logic. Metadata gating is covered at the HTTP integration boundary.
- Integration: Isolated temporary DB and materials directory verify that `/api/materials/overlap-list` includes only AI-provenance summaries and preserves summary text.
- E2E: With deterministic route fixtures, verify a file-backed material displays its AI summary and a text-only material without one shows the not-generated state; verify audio loading still works and no summary endpoint is called.
- Other validation: `npm.cmd test`, `git diff --check`.

## Test data / fixtures

- Use the existing isolated E2E saved JSON/audio fixture with a synthetic AI summary response, plus a text-only DB material with no AI summary.
- Integration fixtures use a temporary SQLite database and synthetic materials folder; never read production `dataset/vocab.db` or `practice_data`, and never call paid APIs.

## Implementation

The overlap list response now identifies an AI summary only when saved summary metadata includes its model provenance. The metadata panel displays the labeled AI summary or a not-yet-generated state, while preserving the saved JSON description separately. Selecting material details triggers no summary generation.
