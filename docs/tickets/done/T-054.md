# T-054: Expand the interface with the available screen width

- Status: In Progress
- Priority: P1
- Requirements: OVER-005
- Dependencies: T-053

## Background

The application main area is capped at 1240px and the overlap control panel uses a nearly fixed width. On wide displays, the interface leaves excessive unused space and the transcript remains narrow.

## Scope

- Included: Increase the responsive maximum width of the application and scale the overlap transcript/control columns with the viewport; retain a usable stacked layout on narrow screens.
- Excluded: Changing page content, typography scale, or the behavior of playback controls.

## Acceptance criteria

- [x] Main content expands beyond 1240px on wide screens and stays centered with consistent outer margins.
- [x] The overlap transcript and settings sidebar both gain width as the viewport grows.
- [x] Narrow-screen layout remains stacked and does not create horizontal overflow.
