# T-037: Repeat one sentence during overlap practice

- Status: Complete
- Priority: P1
- Requirements: OVER-001, OVER-004
- Dependencies: T-035

## Background

The overlap player can repeat the whole material but offers no focused rehearsal of a difficult sentence. Learners need a clear, low-effort way to hear and speak along with one sentence multiple times.

## Scope

- Included: A repeat control on every timed sentence, R-key toggle for the current sentence, visible active target, repeat across the sentence's word-timestamp boundaries, switching and cancelling behavior.
- Excluded: Re-transcription of old materials that have no word timestamps.

## Acceptance criteria

- [x] Clicking a sentence repeat control plays that sentence repeatedly until cancelled or another sentence is chosen; the active target is clear and can be cancelled with the same control.
- [x] R toggles repeat for the current sentence without capturing keys in editable controls; controls remain usable by mouse and Tab/Enter.
- [x] Sentence repeat takes priority over whole-material repeat; loading new audio clears the target; ordinary play/pause and seek remain predictable.
- [x] Untimed sentences have disabled controls with an explanation, rather than inaccurate looping.
- [x] Isolated E2E coverage exercises the two-sentence boundaries, switching, keyboard, pause/resume, and missing-timing case.

## Test data / fixtures

- Two synthetic WAV/JSON saved materials in `tests/e2e_server.py`, with known sentence timestamps and one missing word timeline. No production files or paid API calls.

## Implementation

Each sentence card has a repeat button with pressed state and a visible active border. The R key toggles the sentence at the playback position. Loop boundaries use aligned word timestamps, and the last sentence ends just after its final word. Selecting another sentence switches the loop; clicking a word or using back/restart clears it. Loading new audio resets selection. An untimed sentence keeps its control disabled and shows an explanation.
