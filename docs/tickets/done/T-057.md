# T-057: Show progress while generating audio and subtitles

- Status: Complete
- Priority: P1
- Requirements: OVER-007
- Dependencies: none

## Background

Audio and subtitle generation currently shows a single busy message until all API work finishes. Learners cannot tell whether generation is progressing or waiting on a slow API stage.

## Scope

- Included: Show a percentage that updates at roughly one-point granularity, with a named phase for text generation, audio generation, transcription, and saving; label percentage as estimated when the API does not expose exact completion.
- Excluded: Changing providers, reducing API charges, or changing generated audio/subtitles.

## Acceptance criteria

- [x] Generation displays a visible progress bar and percentage from start to completion, including human-readable phase status.
- [x] Progress advances during long audio generation and transcription work, never reaches 100% before success, and reports errors without leaving a spinning state.
- [x] Progress callbacks are covered with deterministic fixtures and no paid API calls.

## Test plan

- Unit: Verify bounded, monotonic percent calculations from synthetic stage updates.
- Integration: Exercise progress events at text/audio/transcription/save boundaries with mocked API functions.
- E2E: Verify visible progress changes and terminal success/error states using the isolated app and synthetic API fixtures.
- Other validation: `npm.cmd test`.

## Test data / fixtures

- Reuse the isolated HTTP/E2E server with mocked OpenAI endpoints and synthetic audio; no production data or paid APIs.

## Implementation

The generation endpoint streams NDJSON progress events for preparation, text generation, audio generation, transcription, and saving. Realtime audio delta volume and completed transcription chunks advance the estimate. During provider calls without progress callbacks, the browser advances by one point every 400 ms, bounded by the current phase, so the UI remains responsive without claiming provider-side exact completion.
