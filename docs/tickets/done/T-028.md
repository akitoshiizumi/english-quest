# T-028: 学習統計を独立したダッシュボードページにする

- Status: Complete
- Priority: P1
- Requirements: STAT-001, STAT-002, STAT-003
- Dependencies: none

## Background

学習統計が語彙練習タブ内にあり、日々の練習操作と振り返りが同じ画面に混在している。統計を専用ページにまとめ、学習状況を一目で確認できるようにする。

## Scope

- Included: 独立したダッシュボードページ、期間切り替え、既存の語彙・オーバーラッピング指標、語彙DBの規模と学習実績（集計・語彙別）の表示。
- Excluded: 既存履歴の意味の推測変換、新たな分析用外部API。

## Acceptance criteria

- [x] 学習統計が独立したページとしてナビゲーションから開け、語彙練習画面から分離される。
- [x] 期間切り替えに応じて日別学習数、自己評価正解率、語彙練習時間、オーバーラッピング時間、合計、学習日数、復習予定を表示する。
- [x] 指標の定義と旧履歴の扱いが利用者に分かる。活動がない期間、履歴なし、部分データでも空状態を表示する。
- [x] データベース全体について、登録語彙数（アクティブ/アーカイブ）、学習登場数、正解数、不正解数、自己評価正解率、未登場語数を表示する。DB全体の累積値と選択期間の値を区別する。
- [x] 語彙別に登場数、正解数、不正解数、正解率を確認でき、登場数・正解率などで並べ替えてよく使う語・苦手語を見つけられる。
- [x] 正解率は正解数 / 評価済み登場数で計算し、未学習語や旧履歴など評価できない記録は分母に混ぜず、集計対象数を併記する。
- [x] ページ更新や直接URLアクセス後もダッシュボードを開け、キーボード・狭い画面で利用できる。
- [x] 既存の統計APIと時間集計の意味を維持し、期間境界で二重計上しない。

## Test plan

- Unit: 期間集計、空期間、旧履歴、時間重複境界、語彙ごとの登場/正解/不正解/正解率集計、0件分母。
- Integration: 一時DBの語彙・学習・重ね読み記録から全体・語彙別・期間別統計を取得。
- E2E: ナビゲーション、期間切り替え、指標表示、空状態、直接ロードを確認。
- Other validation: `npm test`。

## Test data / fixtures

- 一時DBに複数日の語彙履歴と重ね読み時間、期間境界の記録、旧履歴、活動なし期間を持つ合成データを用意。本番データは使わない。
- 全正解、全不正解、混合、未登場、履歴なし、アーカイブ済みの語彙を含め、分子・分母・全体/期間別の区別を検証する。

## Implementation

統計APIにDB全体の在庫・累積学習指標と語彙別の全期間実績を追加。統計表示を語彙練習から独立した `#dashboard` ページへ移し、期間別学習推移、DB集計カード、検索・並べ替え可能な語彙実績表を追加。
