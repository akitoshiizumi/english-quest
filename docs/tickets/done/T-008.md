## 実装結果

語彙選定は weakness-v1（未学習優先、方向別の既知率が低い順、試行数、見出し語・語義IDで安定ソート）。旧方向不明履歴は順位計算から除外し、選定理由を表示する。復習は simple-interval-v1 としてagain=1日、known=3日後、語彙と方向ごとの最新回答を基準にAsia/Tokyo日付で期限を計算。統計画面に今日の期限語彙・新規件数、日別回答数・自己評価率・活動時間、学習日数を表示。

## 確認結果


npm.cmd test 成功（Python 36件、キーボード3件、Playwright 7件）。Python temporary DBで東京日付境界、again期限、known未期限、重複idempotency、旧履歴除外を確認。Playwrightは学習操作・オーバーラップ後の統計表示を確認。空履歴は0件/nullで表示。実データ・OpenAI API不使用。
