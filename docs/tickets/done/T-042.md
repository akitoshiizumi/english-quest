# T-042: Repeat only the timestamped sentence audio

- Status: Complete
- Priority: P1
- Requirements: OVER-004
- Dependencies: T-041

## Background

The current player notices a sentence boundary only after playback passes it. A 0.15-second guard masks late callbacks, and silent E2E audio cannot reveal audible leakage.

## Scope

- Included: Remove the 0.15-second guard, constrain repeat audio to the timestamped sentence clip, preserve lead-in, gap, Space/R/mouse controls, and verify with audible synthetic audio.
- Excluded: Correcting inaccurate transcription timestamps in existing materials.

## Acceptance criteria

- [x] The repeat clip ends at the selected sentence's final word end (capped by the next sentence start) without a 0.15-second offset; it contains no samples from the next sentence's timestamped interval.
- [x] The 0.25-second lead-in, 1.5-second gap, and keyboard/mouse controls continue to work; leaving repeat restores full-material playback.
- [x] Audible two-sentence E2E fixture verifies the clip content and repeat behavior; invalid timing disables repetition.

## Test plan

- Unit: Check sample-boundary slicing using synthetic decoded audio.
- Integration: Saved WAV/JSON fixture through the HTTP endpoints and browser audio decoding.
- E2E: Select sentence, inspect actual clip samples, repeat and restore playback with Playwright.
- Other validation: `npm.cmd test`, `git diff --check`.

## Test data / fixtures

- Synthetic two-tone WAV: first and second sentences use distinct tones; timestamps align with tones. Existing close/untimed fixtures cover invalid timing.

## Implementation

The browser decodes the loaded audio and creates a temporary PCM WAV containing only the selected sentence's timestamped samples. The native audio element plays this finite clip and its `ended` event starts the existing 1.5-second gap. The clip begins 0.25 seconds before the first word, where available. Releasing repetition restores the full audio and timeline position. The old frame/timeupdate boundary watcher and 0.15-second guard are removed.
