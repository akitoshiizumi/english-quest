# T-059: Explore vocabulary performance distributions

- Status: Done
- Priority: P1
- Requirements: STAT-005
- Dependencies: T-028, T-058

## Background

The dashboard shows individual vocabulary rows and outcome charts, but does not show how the vocabulary population is distributed across outcome ranges. Learners need to see how many words fall into each self-reported accuracy or practice-count range, and switch the measure being explored.

## Scope

- Included: Add a selectable vocabulary distribution chart with vocabulary count on the vertical axis and selectable self-reported accuracy, attempt count, known count, or retry count on the horizontal axis. Keep the chart in sync with the current vocabulary search.
- Excluded: New API or database aggregation, per-date distribution, changes to statistics semantics, and third-party chart libraries.

## Acceptance criteria

- [x] Learners can select accuracy, attempts, known answers, or retry answers as the distribution axis; the vertical axis always counts vocabulary items and bins are labeled.
- [x] Accuracy distribution excludes words with no answers and states how many are excluded; count distributions include unseen words in the zero bin.
- [x] Distribution follows the vocabulary search, provides useful empty states, and remains readable with sparse or high counts and narrow screens.
- [x] Metric selection is keyboard accessible and existing vocabulary tables and per-word charts remain available.

## Test plan

- Unit: Test pure distribution binning for each metric, boundary values, unstudied rows, and empty input with Node tests.
- Integration: Verify the new static distribution helper is served through the asset allowlist and the existing `/api/statistics` payload remains unchanged.
- E2E: In an isolated mocked dashboard response, switch each axis, verify bins and counts, search filtering, empty states, keyboard selection, and narrow-screen layout.
- Other validation: `npm.cmd test`, `node --check`, `git diff --check`.

## Test data / fixtures

- Add synthetic per-word statistics rows covering no answers, exact accuracy bin boundaries, zero counts, and large counts to unit and mocked E2E fixtures.
- Tests use isolated temporary databases and deterministic mocked statistics responses; never access production `dataset/vocab.db` or `practice_data`.

## Implementation

Added a vocabulary-distribution histogram with selectable self-reported accuracy, total attempts, known answers, and retry answers. Accuracy is grouped in 10% bands; count metrics use single-value buckets from 0 through 5, then 6–10, 11–20, and 21+. Accuracy excludes unstudied vocabulary and reports the excluded count, while count metrics include unseen vocabulary at zero. Distribution is calculated from the searched rows and rendered as an accessible SVG without changing the API.
