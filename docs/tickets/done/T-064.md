# T-064: Select due vocabulary for review practice

- Status: Complete
- Priority: P2
- Requirements: REVIEW-001
- Dependencies: T-038, T-050

## Background

The application calculates due vocabulary from answer history and shows a due count on the dashboard, but learners cannot start practice directly with that due set. They must recreate the target with manual history filters.

## Scope

- Included: Add a due-review target to vocabulary practice. Select items from the latest answer per vocabulary and direction using the existing simple-interval-v1 schedule (again: 1 day, known: 3 days); sort by oldest due date first; honor direction, category, CEFR difficulty, and question count. Keep standard practice for new and condition-filtered vocabulary; explain when no items are due.
- Excluded: Changing answer ratings, schedule intervals, historical events, or adding paid API calls.

## Acceptance criteria

- [x] Learners can start practice with only due vocabulary selected automatically from existing answer history; direction-specific history determines eligibility.
- [x] Due items are ordered by oldest due date first and filtered by the selected category, CEFR level, and question count.
- [x] New vocabulary and existing custom filters remain available in standard mode; due mode explains an empty due set.
- [x] Tokyo calendar-day boundaries and latest-answer behavior match the dashboard's existing simple-interval-v1 due calculation.

## Test plan

- Unit: Temporary SQLite cases cover due/overdue, not-yet-due, new words, direction separation, ordering, category/difficulty, and later answers that change the schedule.
- Integration: Isolated `/api/next-question` requests verify due-only mode, empty results, count, and standard-mode compatibility.
- E2E: Start due review, verify only due items appear in due order, select direction/category/difficulty/count, check no-due state, and confirm standard new-word practice remains available.
- Other validation: `npm.cmd test`, `git diff --check`.

## Test data / fixtures

- Synthetic answer events with fixed timestamps in a temporary SQLite database; no production database or paid API.

## Implementation

The practice page now offers a due-only vocabulary set selected from the latest directional study history, ordered by due date.
