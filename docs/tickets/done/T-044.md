# T-044: Add direct page navigation and richer study-set filters

- Status: Complete
- Priority: P1
- Requirements: DATA-005, FLOW-001, SELECT-001
- Dependencies: T-029, T-013

## Background

Users managing thousands of words must click page controls repeatedly. Study-set creation also accepts free-text themes and cannot select vocabulary by recent accuracy and number of prior answers.

## Scope

- Included: Editable current-page number in the vocabulary pager; category options for study-set theme; filters for minimum recent answer history and maximum recent self-rated accuracy, including handling insufficient history.
- Excluded: New ranking algorithm, changes to regular vocabulary practice filters, or API-powered theme generation.

## Acceptance criteria

- [x] Users can enter a page number, submit with Enter, and reach the corresponding range; values outside valid bounds are safely clamped.
- [x] Study-set theme is selected from categories and restored across reloads; it is sent to the planner and generator as the category name.
- [x] Study-set planning applies recent-answer-count and recent-accuracy filters in the selected direction, reports the resulting count, and persists filter settings.
- [x] Existing category, mastery, difficulty, selection, generation, and save paths continue to work.

## Test plan

- Unit: N/A for UI fields; existing database filter function is covered by integration fixtures.
- Integration: Temporary DB with varied answer histories verifies count and accuracy filtering, direction-specific events, category theme persistence.
- E2E: Jump to page 5 of a synthetic 16,920-row response; choose category theme and accuracy filters, plan, and verify request/selected results and saved conditions.
- Other validation: `npm.cmd test`, `git diff --check`.

## Test data / fixtures

- Existing isolated pagination fixture plus mocked 16,920-row response for page 5. HTTP temporary database fixture uses mixed history and answer directions.

## Implementation

Added a direct page-number input beside the range display, with Enter/change submission and bounds clamping. Replaced free-text study-set theme with a category dropdown. Added recent N-answer count, recent self-rated accuracy ceiling, and insufficient-history option. The planning API now persists/applies these filters by direction and scans candidate vocabulary beyond the former first-500 row cap, loading event batches safely.
