# T-016 機能別タブとデータベース管理画面

- 状態: 完了（2026-10-24）
- 優先度: P1
- 要求ID: UI-003, DATA-002, DATA-003
- 依存: T-015

## 目的

主要機能を専用タブへ整理し、語彙・教材・データベースの管理場所を明確にする。

## 受け入れ条件

- [x] 「オーバーラッピング」「語彙練習」「語彙管理（閲覧・編集）」「語彙追加」「データベース管理」の5タブを表示する。
- [x] タブ間をマウスとキーボードで移動でき、選択中タブとフォーカスを視認できる。
- [x] タブ移動・再読み込み後も、画面状態や編集中データを不意に失わない。未保存変更は警告する。
- [x] 語彙閲覧・編集、語彙追加、既存教材再生、オーバーラッピング生成を対応するタブに配置する。
- [x] データベース管理でスキーマ版・保存先・最終バックアップ等を確認し、バックアップと復元を実行できる。
- [x] 復元など上書き操作は対象と影響を確認でき、失敗時に既存DBを壊さない。
- [x] 主要画面のマウス・キーボード操作をPlaywrightで確認する。

## テスト

合成DBでタブ切替、未保存変更、バックアップ・復元成功/失敗をHTTP統合とPlaywright E2Eで確認する。実DBには触れない。


## 実施結果（2026-10-24）

- React GUIで主要機能を5タブに整理し、マウスとキーボードによるタブ移動を追加。
- データベース管理タブでスキーマ版、保存先、バックアップ状態を確認し、バックアップ・復元操作を提供。
- 失敗時に既存DBを保持する復元経路と、未保存変更の警告を含む画面操作を確認。
