# T-019 語彙練習・オーバーラッピング時間の分離統計

- 状態: 完了（2026-10-24）
- 優先度: P1
- 要求ID: STAT-001, STAT-002, LOG-001, OVER-002
- 依存: T-008, T-012

## 目的

語彙練習とオーバーラッピングに費やした時間を個別に記録し、学習の配分を把握できるようにする。

## 受け入れ条件

- [x] 語彙練習では回答操作間の実時間をセッション・日時とともに記録する。
- [x] オーバーラッピングでは実再生時間を現在の集計規則で記録する。
- [x] 統計に語彙練習時間、オーバーラッピング時間、合計時間を別々に表示する。
- [x] 日別と選択可能な期間別の集計を表示し、空データ・旧履歴を誤解なく扱う。
- [x] 中断、タブ移動、ページ離脱、再送で時間を二重計上しない。
- [x] 音声練習時間を語彙練習時間へ混入せず、既存の語彙正答率・復習予定を維持する。

## テスト

固定日時の一時DBで各活動種別の境界・集計・冪等性を統合テストする。Playwrightで語彙練習と音声練習を行い、個別時間と合計の表示を確認する。実データを使わない。

実施結果（2026-10-24）: `npm.cmd test` 成功（Python 42件、キーボード3件、Playwright 12件）。`py -m compileall -q english_overlap tests` と `git diff --check` も成功。OpenAI APIへの実接続および実データは使わず、fixture/一時DBで検証。
