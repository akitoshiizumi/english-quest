# T-055: Keep the focused sentence at the top of the transcript

- Status: Complete
- Priority: P1
- Requirements: OVER-006
- Dependencies: T-053, T-054

## Background

During audio aligned speaking practice, the highlighted sentence can appear anywhere inside the transcript viewport. Learners want each newly focused sentence aligned to the top so they can read it consistently.

## Scope

- Included: Scroll the transcript container to align each newly focused sentence block with its top edge while follow scrolling is enabled; make every software development request start with a tracked ticket.
- Excluded: Changes to audio timing, playback navigation, and the existing responsive layout.

## Acceptance criteria

- [x] When playback focus moves to another sentence and follow scrolling is enabled, that sentence block aligns to the top of the transcript viewport.
- [x] Focus changes within one sentence do not repeatedly scroll; disabling follow scrolling prevents automatic movement, and playback controls remain available.
- [x] All development requests in this repository are ticketed and indexed before implementation.

## Implementation

The player tracks the focused sentence index and scrolls the transcript container to that sentence's top only when the index changes and follow scrolling is enabled. The ticket workflow now requires opening and indexing a ticket before any development edits.
