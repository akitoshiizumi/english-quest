# T-046: Explain empty study-set filter results

- Status: In progress
- Priority: P1
- Requirements: FLOW-001, SELECT-001
- Dependencies: T-045

## Background

When study-set filters produce no eligible vocabulary, the UI says the category has no vocabulary even when it contains many words. Older history rows do not store learning direction and are not eligible for directional recent-answer filters, which can make the result surprising.

## Scope

- Included: Return a compact diagnostic for directional answer-history coverage and legacy history excluded from directional filtering; show actionable empty-result guidance.
- Excluded: Guessing or migrating a direction for legacy history, changing filter semantics.

## Acceptance criteria

- [x] Empty results are reported as no vocabulary matching the selected conditions, not as an empty category.
- [x] When recent history filters are active, the UI shows the number of current directional-history vocabulary items and explains legacy history exclusion when applicable.
- [x] Diagnostic counts respect category and direction for current event history; legacy count is clearly labeled direction-unknown.
- [x] Existing non-empty planning/generation flow remains unchanged.

## Test plan
