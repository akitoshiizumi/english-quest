# T-021 GUIのモダン化と出題語の強調

- 状態: 完了（2026-10-24）
- 優先度: P1
- 要求ID: UI-001, UI-003, UI-004, VOC-001
- 依存: T-015, T-019

## 目的

機能タブ全体の視覚デザインを統一し、語彙練習の出題語をひと目で読める学習中心の画面にする。

## 受け入れ条件

- [x] 全タブに一貫した配色、文字階層、余白、カード、ボタン、フォーム、表のデザインを適用し、モバイル幅でも崩れない。
- [x] 語彙練習はフィルターと出題表示を視覚的に分け、練習中は対象語を大きく中央に表示する。
- [x] 答えと「もう一度」「覚えていた」の状態を見分けやすくし、既存の複数キーとマウス操作を維持する。
- [x] キーボードフォーカス、読み上げラベル、コントラストを維持する。
- [x] Playwrightで英→日・日→英の画面構造、回答操作、主要幅での表示を確認する。

## テスト

合成データを用いる。React build、HTTP統合、Playwright E2Eを実行し、既存のタブ・ショートカット・統計表示を回帰確認する。

実施結果（2026-10-24）: `npm.cmd test` 成功（Python 44件、キーボード3件、Playwright 13件）。`py -m compileall -q english_overlap tests` と `git diff --check` も成功。Playwrightの `vocabulary-modern.png` で語彙カードを確認。UIの英日両方向・キーボード回答・390px表示をE2Eで検証。
