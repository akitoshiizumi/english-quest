# T-015 React GUIへの移行

- 状態: 完了
- 優先度: P1
- 要求ID: UI-003
- 依存: T-003, T-014

## 目的

既存のブラウザGUIをReactへ段階的に移し、機能ごとの画面分割と今後のUI改善を可能にする。

## 受け入れ条件

- [x] React + TypeScript（`.tsx` / `.ts`）を用いたビルド・開発手順を用意し、Pythonサーバーが本番用静的成果物を配信する。
- [x] 既存のAPIキーをブラウザへ渡さず、既存HTTP API契約を維持する。
- [x] 既存機能を移行し、React化前と同じ主要ユーザーフローを維持する。
- [x] キーボード操作、複数キー割り当て、入力欄でのショートカット抑止、マウス操作を維持する。
- [x] テスト環境からReactアプリを起動し、Playwrightで主要タブと学習フローを確認する。
- [x] ビルド成果物を含める方法、依存更新、開発者向け起動・検証コマンドを文書化する。

## テスト

- Python/HTTP統合: API契約と静的成果物配信。
- Playwright E2E: React起動、語彙練習、オーバーラッピング、キー操作。
- 合成DB・固定providerを用い、実データと有料APIを使用しない。

## 設計メモ

React 19.3 + TypeScript 7 + Vite 8を採用。ビルド成果物は `english_overlap/static/app/` に置き、Git管理する。通常利用時にNodeサーバーは不要。開発用ViteサーバーはPython APIへproxyする。

## 実装結果

画面を5つのReactタブとTypeScriptコンポーネントに移行し、既存学習機能・API経路・キーボード操作を維持。Viteビルド成果物をPythonサーバーから安全に配信し、開発時はVite proxyを利用する。React/TypeScript依存と生成物の更新、Windows起動手順を記録。

## 確認結果

`npm.cmd test` 成功: React/TypeScript型検査・Vite build、Python 36件、キー操作3件、Playwright 8件。Playwrightで5タブ、矢印/Home/Endによる移動、語彙練習、教材生成・保存、オーバーラッピング再生、キー設定永続化を確認。HTTP統合でReact bundle配信とAPI契約を確認。固定fixture・一時DBのみ使用し、実API不使用。`py -m compileall -q english_overlap tests` も成功。
