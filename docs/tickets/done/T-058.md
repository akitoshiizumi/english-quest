# T-058: Add graph views to vocabulary and daily learning results

- Status: Done
- Priority: P1
- Requirements: STAT-004
- Dependencies: T-028, T-043

## Background

The learning dashboard exposes per-vocabulary outcomes and daily learning activity only as tables. The daily results section also lacks a clear title. Learners need visual summaries and an easy way to switch between exact rows and graphs.

## Scope

- Included: Add table/graph view controls to vocabulary performance and daily learning results; provide clearly titled sections; chart existing correct/again counts per vocabulary and daily answers/time without changing their calculations.
- Excluded: New statistics endpoints, changes to study-history aggregation, and third-party chart dependencies.

## Acceptance criteria

- [x] Vocabulary learning results have a clear title and switch between the existing searchable/sortable table and a chart with correct/again counts and known rate.
- [x] Daily learning results have a clear title and switch between the existing table and charts for daily answers and study time.
- [x] Charts update when the selected period, search, or sort changes; empty data, long labels, and narrow screens remain usable.
- [x] View controls are keyboard accessible and preserve the existing summary and tabular data.

- E2E: On isolated dashboard fixtures, switch both sections between table and chart, verify values/labels and current filters, use keyboard controls, check empty and narrow-screen layouts.
- Other validation: `npm.cmd test`, `git diff --check`.

## Test data / fixtures

## Implementation

Added keyboard-operable table/chart controls to vocabulary and daily learning results. Vocabulary chart uses the filtered/sorted rows and shows known/retry counts and known rate. Daily charts switch between known/retry answers and vocabulary/overlap study minutes. Daily results now have a dedicated title and region. Summary and original tables remain available.
