# T-060: Delete a saved learning material

- Status: Done
- Priority: P1
- Requirements: DATA-006
- Dependencies: T-028, T-050

## Background

Learners can archive and restore saved materials but cannot permanently remove unwanted items. The material list needs an explicit, confirmed delete action that also cleans up unshared generated media without damaging vocabulary, study history, or other materials.

## Scope

- Included: Add a confirmed delete action to every saved-material row; remove the material record, its vocabulary links, and its generated audio/subtitle files when safely stored in the active materials directory and not referenced by another material; refresh the list and report cleanup errors.
- Excluded: Deleting vocabulary, vocabulary answers, overlap activity history, unrelated files, or files outside the active materials directory; bulk deletion.

## Acceptance criteria

- [x] Each material row offers an accessible delete button and confirmation identifies the selected title and what will be removed.
- [x] Cancelling leaves the material and files unchanged; confirming removes the material and vocabulary links, refreshes the list, and preserves vocabulary and learning history.
- [x] Associated unshared generated audio/subtitle files inside the active materials directory are removed; shared, missing, unrelated, and out-of-directory paths are not deleted.
- [x] Missing material IDs return a not-found response; file cleanup failures are reported without claiming the files were removed.

## Test plan

- Unit: Test safe artifact path validation and duplicate/shared reference filtering with temporary folders.
- Integration: Use an isolated temporary database and materials directory; verify deletion/cascade of material links, preserved vocabulary/history, safe artifact cleanup, shared-file retention, and unknown ID handling.
- E2E: Verify delete button, cancel, confirmed deletion, list refresh, keyboard-accessible confirmation flow where supported, and existing archive/restore behavior.
- Other validation: `npm.cmd test`, `git diff --check`.

## Test data / fixtures

- Synthetic material records, vocabulary links, history rows, and generated MP3/JSON artifacts under isolated temporary test storage; include shared and traversal/outside-path cases.
- Tests must not access production `dataset/vocab.db` or `practice_data`.

## Implementation

Added a delete action to each saved-material row with a title-specific confirmation. Deletion removes the material row and cascaded vocabulary links; it leaves vocabulary and learning-history rows intact. Generated audio/subtitle artifacts are removed only when the path is a valid app filename inside the active materials directory and no other material references it. The endpoint returns cleanup details and not-found for unknown IDs; the UI reports incomplete file cleanup separately.

## Limitations

If the database deletion succeeds but the filesystem refuses to remove an eligible media file, the material is deleted and the UI reports that the file remains. Such cleanup errors may require manual file removal.
