# T-065: Add focus mode to vocabulary practice

- Status: Complete
- Priority: P2
- Requirements: UI-005
- Dependencies: none

## Background

The vocabulary practice page shows filters, navigation, key settings, and other controls alongside questions. Learners need an optional view that hides surrounding interface while preserving the answer and rating actions needed to complete a question.

## Scope

- Included: Add a focus-mode toggle to vocabulary practice. Focus mode shows only the question stage, reveal/rating actions, progress/status, and an exit control; exit by button or Escape; restore the full page on exit.
- Excluded: Changing question content, answer behavior, keyboard bindings, or persisting the focus preference across sessions.

## Acceptance criteria

- [x] Mouse and keyboard users can enter and exit focus mode; Escape exits it.
- [x] Focus mode hides the page header, tabs, practice filters, key settings, and unrelated panels while keeping the prompt, answer, history, progress, and answer/rating controls usable.
- [x] Exiting focus mode restores the complete practice page without changing the active question, phase, or saved keyboard settings.
