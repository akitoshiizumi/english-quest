# T-069: Make major page sections collapsible

- Status: 完了
- Priority: P2
- Requirements: UI-006
- Dependencies: none

## Background

Long pages such as vocabulary management show several unrelated tools at once. Users need to collapse sections they are not using while keeping the main areas easy to discover.

## Scope

- Included: Add accessible, independently collapsible sections to the major panels on the overlap, vocabulary practice, vocabulary management, add vocabulary, database, and dashboard pages. Include vocabulary browsing, saved materials, and CEFR assessment as separate areas.
- Excluded: Persisting each section's open/closed state across page reloads.

## Acceptance criteria

- [x] Major sections on feature pages can be opened and closed from a visible heading using mouse and keyboard.
- [x] Vocabulary list, saved materials, and CEFR assessment can be collapsed independently.
- [x] Sections start open so existing users retain the current initial view; existing controls and IDs continue to function when expanded.
- [x] Dashboard existing disclosures and vocabulary practice focus mode continue to work.
