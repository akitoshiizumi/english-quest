# T-050: Streamline generated study-set handoff

- Status: Complete
- Priority: P1
- Requirements: GEN-002, FLOW-001, OVER-001
- Dependencies: T-011, T-015, T-017

## Background

Saved overlap materials expose UTC ISO timestamps without a timezone cue. Dataset-generated text also requires a separate "save as material" button before it can be used for audio practice, while the generation editor is cramped.

## Scope

- Included: Display saved exercise timestamps in JST in both list and details; remove the separate save button by saving generated materials automatically; keep edits synchronized with the saved material and overlap editor; enlarge the generated-text editor.
- Excluded: Changing stored timestamps, historical records, or database schema.

- [x] Saved overlap-material list and detail timestamps display Asia/Tokyo time with an explicit JST label; stored UTC timestamps remain unchanged.
- [x] The redundant save button is removed and successful dataset sentence generation automatically saves a dataset-linked material.
- [x] The generated material is immediately loaded into the overlap source; edits to generated text update the saved material and overlap source.
- [x] The generated-text editor is visibly taller and remains resizable.
- [x] Tests verify UTC-to-JST boundary conversion, generated material linking/edit persistence, and that no save button is rendered.

## Implementation

The saved exercise list and metadata use explicit Asia/Tokyo formatting for UTC timestamps. Dataset-generated study sets are automatically saved with their selected vocabulary links and loaded into the overlap source. The removed button is replaced by automatic save; changing the generated text updates the saved parent and mirrors the overlap source. The editor has a 320px minimum height and remains user-resizable.
