# T-012 オーバーラッピングと学習記録の統合

- 状態: 完了
- 優先度: P2
- 要求ID: OVER-001, OVER-002, STAT-001
- 依存: T-008, T-011

## 目的・実装範囲

オーバーラッピングと学習記録の統合を実現し、関連要求を満たす。

## 受け入れ条件

- [x] 新規教材と既存教材を同じ入口から再生できる。
- [x] 教材ID、再生中の活動時間、日時、セッションを記録する。
- [x] 停止・シーク・繰り返し・画面離脱の集計規則を定め、重複加算を防ぐ。
- [x] 語彙学習と音声練習を記録・統計画面から振り返れる。

## 必須のテスト確認

- 統合テスト: 実行コマンド、結果、影響を受ける経路を記録する。機能変更では必須。
- E2Eテスト: 受け入れ条件に対応する画面操作シナリオ、実行コマンド、結果を記録する。画面を通る変更では必須。
- 該当しないテスト層があれば、その理由を記録する。
- テストデータ: 使用・追加したfixtureと期待値を記録する。実データ・実APIを使わない。
- テスト未実施や失敗がある間は完了にしない。[テスト方針](../../testing.md)を参照。

## 実装結果

既存の保存教材と新規/DB教材を共通プレイヤーから再生。教材IDでセッション開始し、実再生時間のみを加算（再生速度で補正、seek/wait区間は除外）。pause/end/hidden/pagehideでflushし、各flushにidempotency keyを付けて二重送信を防止。統計で語彙自己評価・復習予定・日別件数と音声活動時間を確認できる。

## 確認結果

`npm.cmd test` — Python 36件、キー操作3件、Playwright 7件すべて成功。HTTP統合でtemporary DB上のセッション・教材ID・重複防止・東京日付境界を確認。Playwrightで既存音声と新規教材の再生、字幕追従、停止時activity保存、語彙統計表示を確認。合成音声fixtureのみ使用。

## 判断・残課題

活動時間は音声位置が連続して進んだ時間だけ記録し、seek・buffer待機・停止を除外する。再生速度分は実時間へ補正する。同じevent idempotency keyの再送は一度のみ記録される。
