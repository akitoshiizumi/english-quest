# T-036: Add an advanced native conversational speech style

- Status: Complete
- Priority: P1
- Requirements: OVER-003
- Dependencies: T-004, T-035

## Background

The strongest existing reduction profile avoids mumbling. Listening practice needs an optional harder profile with spontaneous fast American speech, strong connected speech, and brief mild mumbling while preserving the supplied words.

## Scope

- Included: A selectable Realtime speech profile after the existing extreme profile; prompt guidance for irregular fast cadence, weak forms, elision, assimilation, syllable loss, and occasional trailing off; unchanged text and playback controls.
- Excluded: A guaranteed acoustic difficulty score or paid API evaluation.

## Acceptance criteria

- [x] The overlap speech-style selector offers a clearly labeled harder native-conversation condition.
- [x] Selecting it sends its instructions in the Realtime response request, including preservation of every supplied word in order.
- [x] Existing styles, audio format, fixed output playback speed, and saved style metadata continue to work.
- [x] Synthetic tests cover configuration, request payload, and browser selection without calling OpenAI.

## Test plan

- Integration: Request /app-config from an isolated HTTP server and check the new profile label and ordering.
- E2E: On the overlap page select the new condition and confirm the selected value; no paid generation.
- Other validation: `npm.cmd test`, `git diff --check`.

## Test data / fixtures

- In-memory WebSocket transcript with session.updated, an audio delta, and response.done; isolated HTTP and Playwright fixtures already provided by the test suite.

## Implementation

Added `native_unfiltered` after `reduced_extreme` in the ordered speech styles. The profile gives Realtime explicit fast conversational pacing and strong phonetic reduction while asking it to preserve the text and avoid exaggerated slurring. The existing `/generate` flow persists the selected style in saved material metadata.
