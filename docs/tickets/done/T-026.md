# T-026: AI開発チケットの完了条件と検証記録を標準化

- Status: Complete
- Priority: P1
- Requirements: none (development process improvement)
- Dependencies: none

## Goal

AIがチケットを一貫して処理できるよう、作業範囲、受け入れ条件、テストデータ、検証方法、完了証跡をチケットの共通様式にする。繰り返し起きる失敗を、Skillまたは機械的に検査できるルールへ反映する。

## Acceptance criteria

- [x] `docs/tickets/TEMPLATE.md` に背景、範囲、要件ID、依存、受け入れ条件、テスト計画、fixture、実行結果、制限、変更要約、コミット記録の欄がある。
- [x] テンプレートが、手動で確認可能な受け入れ条件と、該当するテスト層をチケットごとに定義できる。
- [x] `process-ticket` Skill が新規チケット作成時にテンプレートを使い、チケット単位の証跡を記録する。
- [x] Skill が、繰り返し発生した不備を既存ルールの修正、再利用可能な手順、または自動チェックのいずれかで再発防止するよう指示する。
- [x] テスト用データと本番データの分離、実API費用を発生させない自動テスト方針を維持する。
- [x] 文書間の役割が明確で、重複する手順や矛盾がない。
