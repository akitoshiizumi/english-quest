## 重大度の目安

| 重大度 | 判断基準 |
|---|---|
| Critical | 主要タスクが完了できない、データ損失や重大な誤操作につながる |
| High | 頻繁に行う主要タスクで多くの人が停止・失敗する |
| Moderate | 繰り返しの迷い、誤解、余分な操作が生じるが回避手段がある |
| Low | 小さな不整合や見た目の問題で、タスクへの影響が限定的 |

優先順位は利用者への影響、発生頻度、修正規模を個別に記載し、重大度だけで機械的に決めない。

| ID | 画面・再現 | 利用者への影響と根拠 | 重大度 | 影響 / 頻度 / 修正規模 | 対応 |
|---|---|---|---|---|---|
| UX-01 | 語彙練習を開く。キー案内は「A/U 答え / S/I 評価」と表示される。問題表示中は4キーすべてが答えを表示し、答え表示後はA/Uが「もう一度」、S/Iが「覚えていた」を記録する。 | 表示中の状態によって同じキーの意味が変わるが、案内はこの切り替わりとS/Iによる答え表示を伝えない。初回利用者がキー操作を誤解しやすい。 | Moderate | 中 / 高（各練習） / 小 | T-023: 状態別キー案内を明記。Playwrightで案内テキストと実操作を確認。 |

## 問題が見つからなかった項目

- 5タブ間の選択状態と画面遷移はPlaywrightで確認し、今回の固定fixtureでは行き先の不一致を再現しなかった。
- 英→日・日→英の語彙出題、マウス回答、複数キー回答、保存後の再送経路は既存E2Eで確認した。
- 390px幅の全タブでページ自体の横はみ出しは検出されなかった。管理表の一部は表領域内で横スクロールする。
- 文字サイズ、コントラスト比、スクリーンリーダー実機、ズーム200%以上、音声のみの操作は定量・実機検査していない。

## 再現手順と証跡

`npm.cmd run test:e2e` 内の `UX review captures all feature areas at desktop and mobile widths` が5タブを1280pxおよび390pxで巡回し、横はみ出しを検査してスクリーンショットを生成する。スクリーンショットは `tests/e2e-artifacts/ux-*-desktop.png` と `ux-*-mobile.png` に出力され、Git管理外。

T-023/T-024完了後の回帰確認で、誤解を招く案内と進捗の不明瞭さが解消されたことを再確認する。
