# ADR-0001 初期範囲と開発管理

日付: 2026-10-24

## 合意済み

- 語彙学習、教材生成、オーバーラッピング、記録・統計、データ追加・管理、難易度付けを開発対象とする。
- マウスでもキーでも操作でき、1操作に複数キーを割り当てる。初期割り当てはA/UとS/I。
- OpenAI APIはできるだけ最新を使う。
- 過去の教材内の日本語見出し語の修復は行わない。

## 初期設計案

- ローカル・単一学習者を前提に始める。
- 要求・チケットはリポジトリ内Markdownを正本とする。
- 既存データを調査して引き継ぎ、PythonとSQLiteを段階的に整理する。
- 自己評価による語彙学習から開始する。

上記は作業停止条件ではなく、各チケットで調査・判断し根拠を残す対象。
